# Fonts

All four are licensed under the SIL Open Font License 1.1 and are served with the design system, so pages using it make no requests to font hosts.

| File | Family | Source |
|---|---|---|
| `Bricolage-latin.woff2` | Bricolage Grotesque (variable, latin subset) | https://github.com/ateliertriay/bricolage |
| `SourceSerif4-latin.woff2`, `SourceSerif4-italic-latin.woff2` | Source Serif 4 (variable, latin subset), Stead's display face. Browsers only download it on pages that use the Stead look | https://github.com/adobe-fonts/source-serif (licence: `SourceSerif4-OFL.txt`) |
| `Inter-latin.woff2` | Inter (variable, latin subset) | https://github.com/rsms/inter |
| `OpenDyslexic-Regular.woff2`, `OpenDyslexic-Bold.woff2` | OpenDyslexic | See `OpenDyslexic-OFL.txt` |

The latin subsets cover Western European languages. For other scripts, add the matching subsets from the same sources.
