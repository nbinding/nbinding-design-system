nbinding design

A calm, monochrome design system for small, private tools. Dark grey and white, real type, few boxes, and one memorable idea: two hatch directions that become solid where they meet.

See the calendarUsed in Calshare

Principles

  • 1

    Shape before colour

    Every state reads in greyscale: hatch one way, hatch the other, solid, dotted, outlined. Nothing relies on colour alone.

  • 2

    Space, not boxes

    Structure comes from type and whitespace. Panels and cards are the exception, not the frame.

  • 3

    One next action

    Each screen has one obvious primary button, often in the sticky dock.

  • 4

    Comfortable for everyone

    Works at 320px wide, at 150% text, with OpenDyslexic, in light and dark, with a keyboard and a screen reader.

Quick start

No build step. Copy src/ into your project (or link it), then:

<link rel="stylesheet" href="src/nb.css">
<script type="module">
  import { overlay, toast, onHold, prefs, calendar } from './src/js/nb.js';
</script>

Classes start with nb-. Tokens are CSS custom properties starting with --nb-, also in src/tokens.json for design tools.
