# nbinding design

A calm, monochrome design system for small, private tools. Dark grey and white, real type, few boxes, and one memorable idea: **two hatch directions that become solid where they meet.** It powers [Calshare](https://nbinding.github.io/calshare/).

Use the toolbar above any story to switch **Theme**, **Text size**, **Font** (including OpenDyslexic) and **Help with dates**. The **Accessibility** panel runs axe on every story.

## Principles

1. **Shape before colour.** Every state reads in greyscale: hatched one way, hatched the other, solid, dotted, outlined.
2. **Space, not boxes.** Type and whitespace do the structuring.
3. **One next action.** One obvious primary button per screen.
4. **Comfortable for everyone.** 320px wide, 150% text, OpenDyslexic, light and dark, keyboard and screen reader.

## Using it

No build step for the system itself:

```html
<link rel="stylesheet" href="src/nb.css">
<script type="module">
  import { overlay, toast, copy, onHold, prefs, calendar, mark, esc } from './src/js/nb.js';
</script>
```

Classes start with `nb-` (BEM style). Tokens are `--nb-*` custom properties, also in `src/tokens.json`.
